Why this is 22 days, not 83. The 83-day number was the full leftover backlog (RAG, real execute, extra scanners, OPA, full UI, Alembic, JWT). That work is not in this month. This plan ships a hosted demo: RavenX chat + live Nuclei/Trivy scan + findings stored in Postgres + a locked API. Engines are already written. We host them, we do not rebuild them.

1. What “done in 1 month” means

At the end of week 4 a reviewer can:

  1. Open chat and get an answer from RavenX on the cloud VM (llama.cpp).
  2. Run a live Nuclei or Trivy scan (not simulate-only).
  3. See those findings and assets on GET /api/v1/findings and GET /api/v1/assets after a restart (Postgres, not SQLite).
  4. Call the API with a key (not an open internet API).
  5. After a plan is created, simulation runs and an approval request is submitted (no real patch on the server).
